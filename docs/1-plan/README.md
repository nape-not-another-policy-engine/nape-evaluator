# Evaluator Planning

This folder holds evaluator-specific planning, sequencing, and handoff material.

## Structure

- `roadmap.md`
  Current high-level roadmap across active evaluator workstreams.
- `plans/`
  One plan document per active workstream.
- `handoffs/`
  One continuation document per active workstream.

## Rules

- keep evaluator planning here instead of creating `TEMP-` planning files at the root of `docs/`
- update the roadmap when plan status or sequencing changes
- update the matching handoff before stopping active work on a plan
- move lasting conclusions into permanent docs once approved
